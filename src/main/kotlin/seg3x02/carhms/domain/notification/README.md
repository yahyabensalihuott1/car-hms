# Notifications et rappels

**Classification :** Support

Responsabilités :
- courriels de confirmation, de position en liste d'attente, de promotion, d'annulation de randonnée (avec motif) ;
- rappel la veille de la randonnée, avec avertissement si pluie ou neige est prévue ;
- file d'envoi et nouvelles tentatives ; l'envoi technique est délégué à un service de courriel externe.

Concepts : `Notification`, `ReminderComposer`, `EmailSender` (port).
