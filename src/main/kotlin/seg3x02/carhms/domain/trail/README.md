# Catalogue des sentiers

**Classification :** Support

Responsabilités :
- couche anticorruption vers le jeu de données des sentiers publié par la CCN (ArcGIS) ;
- copie locale synchronisée périodiquement (le système fonctionne si la CCN est indisponible) ;
- ne retenir que les sentiers où la randonnée est permise ;
- traduire difficulté, saison d'ouverture, secteur/zone et point de départ dans le langage du club.

Concepts : `Trail`, `TrailDifficulty` (EASY, MODERATE, DIFFICULT, VERY_DIFFICULT), `Season`, `TrailCatalog` (port).
