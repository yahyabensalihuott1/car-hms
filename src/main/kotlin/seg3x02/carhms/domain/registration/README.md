# Inscriptions et liste d'attente

**Classification :** Cœur

Responsabilités :
- admissibilité : adhésion active, difficulté ≤ niveau d'habileté + 1, randonnée ouverte ou complète avant la date limite ;
- places confirmées, liste d'attente ordonnée par heure d'inscription, promotion automatique du premier en attente ;
- annulation d'une inscription.

Concepts : `Registration` (agrégat), `RegistrationStatus` (CONFIRMED, WAITLISTED, CANCELLED), `EligibilityPolicy`.
