# Identité et accès

**Classification :** Générique

Responsabilités :
- authentification par courriel et mot de passe (haché) ;
- sessions, rôles (HIKER, ORGANIZER, ADMINISTRATOR) et autorisation ;
- tout accès autre que la consultation des randonnées exige une authentification.

Concepts : `UserAccount`, `Role`. Mise en œuvre prévue avec Spring Security.
