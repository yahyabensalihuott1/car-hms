# Randonneurs et organisateurs

**Classification :** Support

Responsabilités :
- profil du randonneur (courriel unique, noms, téléphone, adresse, date de naissance, contact d'urgence) ;
- niveau d'habileté, statut d'adhésion (ACTIVE, EXPIRED, SUSPENDED) ;
- décharge de responsabilité (tuteur légal pour les moins de 18 ans) ;
- codes d'invitation à usage unique ;
- certification de chef de randonnée et niveau d'organisateur.

Concepts : `Hiker` (agrégat), `SkillLevel`, `MembershipStatus`, `Waiver`, `LeaderCertification`, `InvitationCode`.
