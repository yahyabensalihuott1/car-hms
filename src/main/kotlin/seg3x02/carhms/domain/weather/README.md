# Météo

**Classification :** Générique

Responsabilités :
- obtenir les prévisions au point de départ d'un sentier pour une date ;
- indiquer si de la pluie ou de la neige est prévue ;
- tolérer l'indisponibilité du service (le rappel part sans avertissement).

Concepts : `Forecast`, `WeatherService` (port).
